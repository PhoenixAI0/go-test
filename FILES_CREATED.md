# Files Created - Complete Summary

This document lists all files created to enable automated training on a fresh server.

## 🎯 Core Files Created

### 1. Dependency Management
- **`requirements.txt`** - All Python dependencies with recommended versions
- **`setup.py`** - Makes go_rl an installable Python package
- **`.gitignore`** - Keeps repository clean (excludes data, models, outputs)

### 2. Automated Scripts (Executable)

#### Main Setup
- **`setup_environment.sh`** ⭐
  - Installs uv package manager
  - Creates Python virtual environment
  - Installs PyTorch with CUDA 12.1
  - Installs all dependencies (unsloth, trl, datasets, etc.)
  - Downloads and configures KataGo
  - Creates directory structure
  - Generates .env file with paths
  - **Time:** ~10-15 minutes

#### Data Preparation
- **`prepare_data.sh`** ⭐
  - Scans for SGF files in data/sgf_9x9/ and data/sgf_19x19/
  - Runs dataset builders (SFT + RL prompts)
  - Validates output JSONL files
  - Reports statistics
  - **Time:** ~1-5 minutes

#### Training Scripts
- **`train_sft.sh`** ⭐
  - Supervised fine-tuning (warm start)
  - Flags: --smoke, --wandb, --board-size, --debug
  - Validates dataset exists
  - Configurable via YAML
  - **Time:** 30-60 minutes (full), 2-5 min (smoke)

- **`train_grpo.sh`** ⭐
  - GRPO reinforcement learning training
  - Flags: --smoke, --wandb, --board-size, --debug
  - Validates KataGo configuration
  - Uses reward shaping with KataGo analysis
  - **Time:** 2-6 hours (full), 5-10 min (smoke)

#### Pipeline Automation
- **`run_full_pipeline.sh`** ⭐
  - Runs complete training pipeline
  - Setup → Data → SFT → GRPO
  - Flags: --skip-setup, --skip-data, --skip-sft, --smoke, --wandb
  - Tracks total time
  - **Time:** ~3-7 hours (full), ~30 min (smoke)

#### Utilities
- **`download_sample_sgf.sh`**
  - Helper for obtaining SGF game files
  - Lists recommended sources
  - Checks if files are present
  
- **`verify_setup.sh`**
  - Comprehensive setup validation
  - Checks all dependencies, KataGo, GPU, datasets
  - Color-coded pass/fail/warning system
  - Provides actionable fixes

## 🚀 Quick Usage Examples

### Example 1: Complete Automated Setup (Recommended)

```bash
# On fresh server with GPU
git clone <repo>
cd go-test

# 1. Add SGF files (user must do this)
cp ~/my_games/*.sgf data/sgf_9x9/

# 2. Run everything (automated)
./run_full_pipeline.sh --smoke  # Test first
./run_full_pipeline.sh          # Full training
```

### Example 2: Step-by-Step Manual Control

```bash
# 1. Setup environment
./setup_environment.sh

# 2. Verify setup
./verify_setup.sh

# 3. Add SGF files
./download_sample_sgf.sh --help  # See instructions
cp games/*.sgf data/sgf_9x9/

# 4. Prepare data
./prepare_data.sh

# 5. Train SFT
./train_sft.sh --smoke          # Smoke test
./train_sft.sh                  # Full training

# 6. Train GRPO
./train_grpo.sh --smoke         # Smoke test
./train_grpo.sh                 # Full training
```

### Example 3: With Weights & Biases Logging

```bash
# Setup once
wandb login

# Train with logging
./train_sft.sh --wandb --wandb-project my-go-project
./train_grpo.sh --wandb --wandb-project my-go-project
```

### Example 4: Training for 19x19 Board

```bash
# Add 19x19 SGF files
cp large_games/*.sgf data/sgf_19x19/

# Prepare data
./prepare_data.sh

# Train
./train_sft.sh --board-size 19x19
./train_grpo.sh --board-size 19x19
```

## 🔍 What Each Script Does

### setup_environment.sh
**Purpose:** Complete environment setup from scratch

**What it does:**
1. Checks for NVIDIA GPU
2. Installs uv package manager (if not present)
3. Creates Python 3.11 virtual environment
4. Installs PyTorch with CUDA 12.1
5. Installs all dependencies from requirements.txt
6. Installs go_rl package in editable mode
7. Downloads KataGo binary (v1.15.3)
8. Downloads KataGo neural network model
9. Creates KataGo analysis config
10. Creates .env file with paths
11. Tests KataGo installation
12. Creates data/, outputs/, logs/ directories

**When to run:** Once on fresh server, or to reset environment

### prepare_data.sh
**Purpose:** Convert SGF files to training datasets

**What it does:**
1. Checks for SGF files in data/sgf_9x9/ and data/sgf_19x19/
2. For each board size found:
   - Parses SGF files
   - Extracts board positions
   - Converts to prompt/response format
   - Writes SFT dataset (data/sft_9x9.jsonl)
   - Writes RL prompts (data/rl_prompts_9x9.jsonl)
3. Reports statistics (number of samples)

**When to run:** After adding new SGF files, before training

### train_sft.sh
**Purpose:** Supervised fine-tuning for warm start

**What it does:**
1. Validates environment is activated
2. Checks dataset exists
3. Loads config (config/sft_warm_start.yaml)
4. Downloads model (qwen-3-8b) if needed
5. Trains with SFTTrainer from TRL
6. Saves checkpoint to outputs/sft_warm_start/
7. Logs to logs/sft_warm_start/

**Flags:**
- `--smoke`: Quick test (1 epoch, minimal data)
- `--wandb`: Enable W&B logging
- `--board-size SIZE`: 9x9 or 19x19
- `--debug`: Verbose logging

### train_grpo.sh
**Purpose:** GRPO reinforcement learning with KataGo rewards

**What it does:**
1. Validates KataGo is configured
2. Tests KataGo binary
3. Checks RL prompt dataset exists
4. Loads config (config/grpo_9x9.yaml)
5. Starts KataGo analysis engine
6. Trains with GRPOTrainer + reward function
7. Saves checkpoint to outputs/grpo_9x9/
8. Logs to logs/grpo_9x9/

**Flags:** Same as train_sft.sh

### run_full_pipeline.sh
**Purpose:** End-to-end automation

**What it does:**
1. Runs setup_environment.sh (unless --skip-setup)
2. Runs prepare_data.sh (unless --skip-data)
3. Runs train_sft.sh (unless --skip-sft)
4. Runs train_grpo.sh
5. Tracks total time
6. Reports final results

**Flags:**
- `--skip-setup`: Skip environment setup
- `--skip-data`: Skip data preparation
- `--skip-sft`: Go straight to GRPO
- `--smoke`: Smoke test all steps
- `--wandb`: Enable W&B logging

### verify_setup.sh
**Purpose:** Validate environment is ready

**What it checks:**
1. Virtual environment exists
2. Python packages installed
3. PyTorch CUDA available
4. KataGo binary working
5. KataGo model exists
6. KataGo config exists
7. SGF files present (9x9)
8. SGF files present (19x19)
9. Training datasets prepared
10. NVIDIA GPU available
11. Shell scripts executable
12. Config files present

**Returns:** Color-coded status with actionable fixes
